## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/rishisingh108/ITqHub.git
```

### Install Dependencies

```bash
npm install
```

### Start Frontend

```bash
npm run dev
```

### Start Backend

```bash
cd backend
npm install
node server.js
```
